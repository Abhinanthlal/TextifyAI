Aim & Objectives

SLIDE 2 OF 5

🎯 Aim of the Project

To develop a lightweight, production-ready Python web application that accepts a paragraph of study text from the user and automatically generates a short summary, a set of 3–5 key study points, and exact reduction statistics using a pre-trained Generative AI model.

📌 Core Objectives

  • ✔ Abstractive Summarization: Condense complex academic paragraphs into fluent abstracts without losing core meaning.
  • ✔ Key Takeaway Extraction: Synthesize 3–5 bulleted points capturing essential concepts.
  • ✔ Reduction Analytics: Compute word counts and percentage reduction using ((Original - Summary)/Original) × 100.
  • ✔ Zero-Cost & Publicly Accessible: Deploy without paid APIs for live college evaluation.

🛠️ Technology Stack

  • • Backend: Python 3.11, Flask Framework
  • • Generative AI: Hugging Face Transformers
  • • Pre-trained Model: facebook/bart-large-cnn
  • • Frontend: HTML5, CSS3 Glassmorphism, JS
  • • Hosting: Cloud Container / WSGI Gunicorn

🧠 Why BART-Large-CNN?

BART combines a bidirectional encoder (like BERT) with an autoregressive decoder (like GPT). Fine-tuned on CNN/DailyMail, it excels at generating natural, grammatically coherent summaries.

🔄 Data Processing Pipeline:

User Input Paragraph / Notes
Flask Backend Validation & Tokenizing
BART Transformer Seq2Seq Inference
Analytics Engine Word Count & Red. %
Results Display Summary & Key Points
